1. Access control (every page)

Every request enters index.php; the Router picks one Page class and its guard decides who may see it.

2. Registration with school-email verification

Only @sanbeda-alabang.edu.ph addresses are accepted. No account exists until the emailed code is entered.

3. Login with email 2FA

Two steps: password first, then a 6-digit code sent by email (10-minute expiry, 5 tries, resend every 60 s).

4. Profile & logout

Shared by members and admins.

5. Member: browse, reserve, cancel

Members search the catalog and reserve a title; stock is the number of available copies.

6. Email notifications: due dates & fees

Runs daily from notify.php (Task Scheduler / cron) or from the dashboard’s “Send reminders now” button. One email per member lists books due soon, overdue books and unpaid fees; a log prevents repeats.

7. Catalog: books & copies

Chief Librarian, IT Staff and System Admin manage the catalog. Librarians can only view it. Each physical copy has its own Book ID (e.g. BK0007-02); only an available copy can be lent.

8. Circulation: borrow a book

Any staff role can lend. One specific copy is lent: leave Copy on auto-assign or pick an exact Book ID.

9. Circulation: return, penalty & fee notice

Returning frees the exact copy that was lent. A late return records the penalty and emails a fee notice to the member.

10. Circulation: reservations

Any staff role sees every member’s reservations.

11. Users & roles (IT Staff, System Admin)

Both can search users and change roles. IT Staff may only manage Members, Librarians and Chief Librarians. Only a System Admin can assign the IT Staff / System Admin roles, change those accounts, or delete users.

12. Reports (Chief Librarian, IT, Admin)

Totals, top borrowers, mark penalties paid, CSV export (includes Book IDs). Librarians do not see this page.
